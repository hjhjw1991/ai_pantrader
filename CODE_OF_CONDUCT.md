# 行为准则 / Code of Conduct

## 简版

就事论事，对事不对人。技术分歧欢迎，人身攻击不行。

Be direct about the work, not about the person. Disagreement is welcome; personal attacks
aren't.

## 具体说

**可以**：直接指出问题、说"这个做法不对，原因是……"、要求对方给出证据、
坚持自己的判断直到被说服。这个项目的代码 review 风格本来就偏直接。

**不可以**：人身攻击、骚扰、歧视性言论、起哄、公开或私下发布他人隐私信息、
以及其它在职业场合里明显不合适的行为。

**Fine**: saying a approach is wrong and why, asking for evidence, holding your position until
persuaded. Review here is direct by default.

**Not fine**: personal attacks, harassment, discriminatory language, trolling, publishing
others' private information, and anything else plainly unprofessional.

## 关于交易内容的额外一条

这个项目处理的是真实的钱。**不要在 issue、PR 或讨论里荐股**，
也不要把这个项目的输出当成投资建议转述给别人。
自己的持仓、账户信息、数据库文件请不要贴出来 —— 对你自己不利，对别人也没用。

This project touches real money. **No stock tips** in issues, PRs, or discussions, and don't
relay its output to others as investment advice. Don't paste your own positions, account
details, or database file — it doesn't help anyone and it exposes you.

## 执行 / Enforcement

维护者可以删除、编辑或拒绝任何不符合本准则的内容，并在必要时封禁账号。

有问题请开 [issue](https://github.com/hjhjw1991/ai_pantrader/issues)；
涉及具体个人的投诉，可以用 GitHub 的
[私密举报](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)。

Maintainers may remove, edit, or reject anything that violates this, and ban accounts when
needed. Raise concerns as an [issue](https://github.com/hjhjw1991/ai_pantrader/issues); for
complaints about a specific person, use GitHub's private abuse reporting.
